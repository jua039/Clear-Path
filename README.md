# Detección de Abandono en Apuestas Deportivas Online
## Proyecto Clear Path × WINBET

---

## Descripción general

Este repositorio documenta el desarrollo completo del proyecto "Detección de abandono (churn) en apuestas deportivas en línea", desde el descubrimiento inicial hasta la solución analítica final.

Clear Path actúa como la empresa externa de analítica de datos e inteligencia artificial encargada de diseñar e implementar la solución para WINBET, plataforma cliente de apuestas deportivas online.

El objetivo es identificar patrones de comportamiento que permitan predecir y prevenir el abandono de usuarios dentro de la plataforma, generando insumos accionables para el negocio.

## Contexto del proyecto

Cliente: WINBET (plataforma de apuestas deportivas online)
Proveedor: Clear Path (analítica de datos e IA)
Problema de negocio: Alta tasa de abandono de usuarios activos
Objetivo: Detectar señales tempranas de churn y habilitar estrategias de retención
Entregables: Modelo predictivo, dashboard Power BI, documentación de descubrimiento

---

## Proceso de descubrimiento

El descubrimiento del proyecto se realizó en un tablero de Miro, donde el equipo mapeó el problema, los actores involucrados, hipótesis de abandono y el flujo de datos disponible.

Documentación completa disponible en la carpeta /discovery

---

## Stack tecnológico

Análisis y modelado: Python (Pandas, Scikit-learn)
Visualización: Power BI
Gestión de datos: SQL
Documentación y descubrimiento: Miro

---

## Dashboard de Power BI

Archivo ubicado en: /dashboard/winbet_churn_dashboard.pbix

El dashboard permite visualizar:
- Segmentación de usuarios por riesgo de abandono
- Tendencias de actividad e inactividad
- Variables más influyentes en la predicción del churn
